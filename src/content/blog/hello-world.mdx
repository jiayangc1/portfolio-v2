This site used to be one page: a photo, my stack, and a list of projects. That worked, but there was never anywhere to say *why* I built any of it, so I gave it some room.

What's new:

- **[About](/about)**: the longer version of me, what I'm working on now, my GitHub activity, and a timeline going back to my first Discord bots in 2021
- **[Projects](/projects)**: a page for each thing I've shipped, with what it does and what it's built with
- **[Uses](/uses)**: my setup (spoiler: a MacBook Pro and a lot of iTerm)
- **Blog**: you're on it

The GitHub heatmap on the About page is my favorite part. It pulls my contributions once a day and draws them in the same grey as the rest of the site, instead of GitHub green.

Most of what I'm building right now is around [Authometry](/projects/authometry) and auth for AI agents, so expect posts about OAuth, MCP, and whatever breaks along the way.

Posts here are plain MDX files in the repo, so writing one is just:

```bash
touch src/content/blog/my-post.mdx
```

There's an [RSS feed](/blog/rss.xml) if you want to follow along.
