This site used to be a single page. It now has a few more:

- **About**: a longer bio, what I'm up to, my GitHub activity, and a timeline
- **Projects**: a page for each thing I've built
- **Uses**: the gear and tools I work with
- **Blog**: this

Posts are plain MDX files in the repo, so writing one is just:

```bash
touch src/content/blog/my-post.mdx
```

There's also an [RSS feed](/blog/rss.xml) if you'd like to follow along.
